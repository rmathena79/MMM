# MMM

Deterministic pipeline for predicting the 2026 men's NCAA tournament main bracket.

Run the full pipeline with:

```powershell
python scripts/run_pipeline.py --year 2026
```

Outputs land in:

- `outputs/main_bracket_predictions_2026.csv`
- `outputs/main_bracket_predictions_2026.json`
- `outputs/play_in_predictions_2026.csv`
- `outputs/summary.md`
- `logs/run_metadata.json`
